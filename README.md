# tell-me-everything

A small slice of a React Native field capture app. Users take photos of a
property and the app uploads them to a job.

Only the JavaScript layer is in this repo. The native iOS and Android projects
and the camera preview view are left out.

```bash
npm install
npm test
npm run typecheck
```

See [ARCHITECTURE.md](ARCHITECTURE.md) for how the code is organized and who owns what.
